## القاعدة اللي الفولدر ده اتعمل عشانها

**أي حاجة الطرق التلاتة محتاجاها بتتكتب هنا مرة واحدة.**

مش قاعدة تنظيمية شكلية — دي جاية من غلطتين حقيقيتين عاشوا شهر:

| الغلطة | سببها |
|---|---|
| `vidtest3` كله موصوف غلط (4 حركات بدل 13) | الجدول كان متكرر في 9 أماكن، اتصلّح في واحد بس |
| الـ `wave` بتاع `vidtest2` متعلّم "سكون" | نفس السبب — الكشف الصح كان بيتحسب إنذار كاذب |

التكرار مش بيعمل بق. التكرار بيخلّي البق **يعيش** لما يتصلّح في نسخة واحدة.

## إزاي تستورد من هنا وأنت في فولدر تاني

كل فولدر طريقة فيه `_bootstrap.py` بيضيف `shared/` لـ `sys.path`:

```python
import _bootstrap  # noqa: F401     ← لازم قبل أي استيراد من shared
from paths import load_keypoints, KP_DIR, out_dir
from ground_truth import GROUND_TRUTH
```

⚠️ **الترتيب مش اختياري.** لو كتبت `from paths import ...` قبل
`import _bootstrap` هتاخد `ModuleNotFoundError`.

## `paths.py` — أول حاجة تشغّلها لو حاجة استغربتها

```bash
python paths.py
```

بيطبع: البيئة (محلي/Kaggle) · كل المسارات · **جابت الـ keypoints منين**
(الريبو ولا الداتاسِت) · ليستة الفيديوهات اللي لقاها.

### ترتيب البحث عن الـ keypoints

```
١. متغيّر البيئة KEYPOINTS_DIR      ← للتجارب، بيكسر كل اللي تحته
٢. shared/keypoints/                 ← بتيجي مع الـ git clone
٣. /kaggle/input/*/keypoints/        ← الداتاسِت المرفوع
٤. /kaggle/working/keypoints/        ← لو اتولدت في نفس الجلسة
```

⚠️ **رقم ٢ قبل رقم ٣ بنيّة، ودي كانت بق فعلي.** أول نسخة كانت بتروح على
الداتاسِت على طول وبتتجاهل الـ `keypoints/` اللي قدامها، فالـ `git clone`
على Kaggle كان هيدوّر في فولدر فاضي رغم إن الملفات معاه في الريبو.
ده اللي بيخلّي FastDTW يشتغل على Kaggle **من غير أي داتاسِت خالص**.

### `KP_DIR` مقابل `KP_OUT` — الفرق مش تفصيلة

على Kaggle الـ `/kaggle/input` **للقراءة بس**. `pose_extract.py` بيكتب
فبيستخدم `KP_OUT` (بيروح `/kaggle/working`)؛ باقي السكريبتات بتقرا
فبتستخدم `KP_DIR`. محلياً الاتنين نفس الفولدر.

### `out_dir(__file__)` — مافيش `results/` واحد

```python
OUT_DIR = out_dir(__file__)     # results/ جنب السكريبت اللي نداها
```

مقصود إنه مش ثابت. كل طريقة بتكتب في `results/` بتاعها عشان محدش يبص
على فولدر واحد ويلاقي فيه مخرجات تلات طرق مخلوطة ومايعرفش مين طلّع إيه.

## `ground_truth.py` — القاعدة الأهم في المشروع كله

⚠️ **متكتبش جدول ground truth بإيدك في أي ملف. استورد من هنا بس.**

```python
from ground_truth import GROUND_TRUTH, actions, spans, project, check
```

عايز مفردات أضيق؟ استخدم `project()` — بيسقّط الجدول المرجعي بدل ما
تكتب جدول تاني:

```python
project('vidtest3', keep=('sit_down', 'stand_up'))
```

### اصطلاح اللابلز

| | المعنى |
|---|---|
| `'other*'` | سكون **متأكّد منه بالمشاهدة** — بيتحسب في التقييم |
| `'?'` | فترة **مش موصوفة** — بتتستثنى من الحساب تماماً |

حطّ فترة مش موصوفة على إنها `'other*'` = **اختراع بيانات**.

⚠️ **خط الأساس "قول other على طول" بيتغيّر مع الفيديو وممكن يبقى صفر.**
الـ GT المصحّح بتاع vidtest3 مافيهوش ولا ثانية `other*` (الـ 56 ثانية دي
`'?'`)، يعني خط الأساس عليه **0.0%** مش 95.7% زي ما كان مكتوب في أماكن
كتير قبل التصحيح. أي رقم دقة لازم يتقال **ومعاه خط الأساس بتاع نفس
الفيديو**.

## `pose_extract.py`

```bash
python pose_extract.py              # الأربع فيديوهات
python pose_extract.py vidtest4     # فيديو واحد
```

محتاج `ultralytics` + `opencv` + ملفات الـ mp4 (`VIDEO_DIR`) — دي الحاجة
الوحيدة في المشروع اللي محتاجة الفيديوهات نفسها.

⚠️ `FRAME_SKIP = 2` — رقم الـ keypoint = رقم فريم الفيديو ÷ 2. أي حساب
بالثواني لازم يستخدم `effective_fps` من الـ meta، مش fps الفيديو.

⚠️ الـ meta مفتاحه `detect_rate` مش `detection_rate`. اقراه بالأقواس
المربعة `meta['detect_rate']` مش `.get()` — عشان الغلطة الإملائية تقع
بصوت عالي بدل ما تطبع "اكتشاف 0.0%" وتعدّي.
