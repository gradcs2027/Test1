**ابدأ من هنا:** افتح `HA4M_report.ipynb` — متشغّل وكل الرسومات والجداول جوّاه (مش محتاج تشغّله).

| الفولدر / الملف | فيه إيه |
|---|---|
| `HA4M_report.ipynb` | التقرير كامل: الداتا ← خط المعالجة ← التقييم ← المراحل ← الموديلات ← مشكلة الكاميرا ← التجربة الكبيرة ← التحليل ← الأخطاء ← الفيديوهات ← الخلاصة + أسئلة متوقعة |
